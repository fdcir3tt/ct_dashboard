
| **Nombre**                            | **Descripción**                                                    | **Variable**         | 
| ------------------------------------- | ------------------------------------------------------------------ | -------------------- | 
| **conjuntos de datos**                | Identificadores de los datasets utilizados para entrenamiento      | `datasets`           | 
| **metricas**                          | Métricas que se quieren evaluar por modelo                         | `metrics`            | 
| **parametros**                        | Parametros para cargar modelo                                      | `parameters`         | 
| **frecuencias**                       | Unidades de tiempo con la cual se entrenará el modelo              | `frequencies`        | 
| **horizontes**                        | Longitudes de periodo que se quiere predecir con modelo            | `horizons`           | 
| **modelos**                           | Tipo de modelos utilizado en entrenamiento                         | `model_types`        | 
| **características**                   | Variables construídas para mejorar rendimiento                     | `feature_set`        | 
| **ventanas de entrenamiento**         | Ventanas de tiempo con las cuales se entrenaran los modelos        | `training_windows`   |  
| **semillas**                          | Semillas utilizadas en el entrenamiento                            | `seeds`              |
